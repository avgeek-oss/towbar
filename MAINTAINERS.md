# Maintainers

Towbar is authored by **Avgeek, Inc.**

The lead maintainer is
[Praveen Thirumurugan (@praveentcom)](https://github.com/praveentcom).

The maintainer reviews changes, coordinates releases, and makes final
decisions. Public contributions are not accepted; feedback and issues are
welcome. Security reports must follow [SECURITY.md](SECURITY.md) instead of
using a public issue.

Maintainer changes are recorded through a pull request updating this file and
`.github/CODEOWNERS`.
