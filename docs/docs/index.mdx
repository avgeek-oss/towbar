Towbar deploys services and datastores to Ubuntu servers you control. Keep workload configuration in Git; manage server access, secret values, and deployment history in Towbar.

## Start with the overview

Open **Overview** to review recent deployments, active incidents, and workloads needing attention. Follow a workload into its current runtime state or deployment history before retrying an operation.

For automation, use the [REST API](/docs/api/overview), [MCP](/docs/api/mcp), or host [CLI](/docs/self-hosting/cli). [Integrations](/docs/integrations) covers source control, storage, notifications, and secret providers.

Manage access in [Team settings](/docs/team-settings) and your account in [Personal settings](/docs/personal-settings). Before exposing Towbar publicly, review the [security model](/docs/self-hosting/security).
