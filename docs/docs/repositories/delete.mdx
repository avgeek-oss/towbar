---
title: "Delete a repository"
description: "Remove a repository connection while preserving its history."
---

1. Move retained workloads to another repository, or explicitly remove them through [Retirements](/docs/repositories/conflicts-and-retirements#permanently-remove-a-retirement).
2. Disconnect all environments and wait for active operations to finish.
3. Open **Repositories → repository → Delete repository** and confirm.

The repository disappears from Towbar's active list. Deployment and sync history, removed workload records, secrets, backup metadata, and runtime ownership evidence remain intact. Historical deployments do not block removal.

Adding the same repository again restores its existing connection and reuses its environment records and secrets. Only the environments you select are reconnected. The Git repository is never deleted.
