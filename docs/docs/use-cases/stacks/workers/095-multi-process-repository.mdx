**Related reading:** [Compose](/docs/services/modes/compose).

The Compose file itself must be committed at the path in the manifest. This page shows Towbar's declaration, not an invented upstream Compose specification. Match the actual service name and internal port when adapting the upstream file.

## Towbar manifest

```yaml title=".towbar/services/web-worker.compose.yml"
id: web-worker
name: Web and worker
file: deploy/web-worker/compose.yml
strategy: maintenance
services:
  web:
    port: 3000
    domains:
      - web-worker.example.com
    ingress:
      type: proxy
environments:
  production:
    server: 192.0.2.10
```

## Configure

1. Register and prepare the example server or servers, connect the repository, and map `production` to the branch containing these files.
2. Commit a Compose file at `deploy/web-worker/compose.yml` with the declared service name and port. Adapt it to [Towbar's Compose restrictions](/docs/services/modes/compose) before syncing.
3. Sync the repository, inspect the resolved configuration, deploy manually, and perform the verification below before enabling automation.

## Verify

Inspect the resolved Compose project, deploy it, and verify every required service is healthy.

For field constraints, see [Compose guide](/docs/services/modes/compose).
