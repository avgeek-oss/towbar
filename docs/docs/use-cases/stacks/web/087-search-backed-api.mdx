## Towbar manifest

```yaml title=".towbar/services/search-backed-api-api.service.yml"
id: search-backed-api-api
name: Search API
deployment:
  type: dockerfile
  context: .
  dockerfile: Dockerfile
container:
  port: 3000
health:
  path: /health
environments:
  production:
    server: 192.0.2.10
secrets:
  runtime:
    - SEARCH_URL
    - SEARCH_KEY
```

## Configure

1. Register and prepare the example server or servers, connect the repository, and map `production` to the branch containing these files.
2. Save the Service's declared keys in its selected environment, or enable and authorize the selected [external-secret provider](/docs/secrets/external). Do not commit the values.
3. Sync the repository, inspect the resolved configuration, deploy manually, and perform the verification below before enabling automation.

## Verify

Index and search a test document through the API. Keep the Meilisearch master key in runtime secrets and back up its volume separately.

For field constraints, see [Service manifest](/docs/services/manifest).
