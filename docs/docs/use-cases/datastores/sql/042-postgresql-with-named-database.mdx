## Towbar manifest

```yaml title=".towbar/datastores/postgresql-with-named-database.datastore.yml"
id: postgresql-with-named-database
name: Named PostgreSQL
type: postgres
container:
  network: application
  networkAlias: postgresql-with-named-database
  resources:
    cpus: 1
    memory: 1g
secrets:
  runtime:
    - POSTGRES_USER
    - POSTGRES_DB
    - POSTGRES_PASSWORD
environments:
  production:
    server: 192.0.2.10
```

## Configure

1. Register and prepare the example server or servers, connect the repository, and map `production` to the branch containing these files.
2. Save each Datastore credential value under **Datastore → Settings → Secrets**, deploy it first, and verify engine readiness before starting a dependent Service.
3. Sync the repository, inspect the resolved configuration, deploy manually, and perform the verification below before enabling automation.

## Verify

After first initialization, connect and check the configured database and role exist. Later changes require SQL, not just new secret values.

For field constraints, see [Datastore manifest](/docs/datastores/manifest).
