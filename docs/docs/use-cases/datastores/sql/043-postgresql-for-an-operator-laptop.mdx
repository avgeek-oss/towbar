## Towbar manifest

```yaml title=".towbar/datastores/postgresql-for-an-operator-laptop.datastore.yml"
id: postgresql-for-an-operator-laptop
name: PostgreSQL tunnel
type: postgres
container:
  network: application
  networkAlias: postgresql-for-an-operator-laptop
  resources:
    cpus: 1
    memory: 1g
secrets:
  runtime:
    - POSTGRES_USER
    - POSTGRES_DB
    - POSTGRES_PASSWORD
environments:
  production:
    server: 192.0.2.10
access:
  sshTunnel:
    hostPort: 15043
```

## Configure

1. Register and prepare the example server or servers, connect the repository, and map `production` to the branch containing these files.
2. Save each Datastore credential value under **Datastore → Settings → Secrets**, deploy it first, and verify engine readiness before starting a dependent Service.
3. Sync the repository, inspect the resolved configuration, deploy manually, and perform the verification below before enabling automation.

## Verify

Forward the loopback-bound database port over SSH and connect with a local PostgreSQL client.

For field constraints, see [Datastore manifest](/docs/datastores/manifest).
