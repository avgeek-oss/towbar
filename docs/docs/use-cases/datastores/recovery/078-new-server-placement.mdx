## Towbar manifest

```yaml title=".towbar/datastores/new-server-placement.datastore.yml"
id: new-server-placement
name: Server placement
type: postgres
container:
  network: application
  networkAlias: new-server-placement
  resources:
    cpus: 1
    memory: 1g
secrets:
  runtime:
    - POSTGRES_USER
    - POSTGRES_DB
    - POSTGRES_PASSWORD
environments:
  production:
    server: 192.0.2.10
  staging:
    server: 192.0.2.11
```

## Configure

1. Register and prepare the example server or servers, connect the repository, and map `production` to the branch containing these files.
2. Map `staging` to its repository branch, register its target server, and save staging credentials separately from production.
3. Save each Datastore credential value under **Datastore → Settings → Secrets**, deploy it first, and verify engine readiness before starting a dependent Service.
4. Sync the repository, inspect the resolved configuration, deploy manually, and perform the verification below before enabling automation.

## Verify

Deploy on the selected environment's server and verify authenticated connectivity with that environment's secrets.

For field constraints, see [Datastore manifest](/docs/datastores/manifest).
