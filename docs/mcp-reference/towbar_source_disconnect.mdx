`towbar_source_disconnect`

Withdraw this repository's declarations without deleting workloads or data. Compatible sole owners adopt existing workloads; other workloads remain as retirements or conflicts. Use source_removal_preview, confirm its impact with the user and pass expectedRevision. Active operations block removal. History, secrets, storage and ownership evidence are preserved.

## Access and behavior

Choose **Administrator** when approving the [MCP connection](/docs/api/mcp). Your current team role and approved permissions constrain access.

Required permissions: `repository.disconnect`.

| Annotation  | Value |
| ----------- | ----- |
| Read-only   | false |
| Destructive | true  |
| Idempotent  | false |

Review the target and effect with the user before running this tool. An idempotent annotation does not make an action reversible.
