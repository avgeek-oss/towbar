`towbar_retirement_remove`

Destructive: confirm the exact manifest ID and storage loss with the user first. Removes this workload's containers, routes and volumes across associated servers; preserves history and backups. A verified Git declaration blocks a new removal request. Once queued, removal reserves the ID until cleanup finishes. Poll every returned operation. Reuse the idempotency key only for a retry of this same request.

## Access and behavior

Choose **Administrator** when approving the [MCP connection](/docs/api/mcp). Your current team role and approved permissions constrain access.

Required permissions: `server.remove`.

| Annotation  | Value |
| ----------- | ----- |
| Read-only   | false |
| Destructive | true  |
| Idempotent  | true  |

Review the target and effect with the user before running this tool. An idempotent annotation does not make an action reversible.
