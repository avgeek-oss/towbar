`towbar_alerts_remove`

Delete an inspected Scout rule, stop its checks/evaluation and close active incidents without claiming recovery. Resolved incident history remains until retention expires. Confirm the user's intended rule before removal.

## Access and behavior

Choose **Write** when approving the [MCP connection](/docs/api/mcp). Your current team role and approved permissions constrain access.

Required permissions: `alert.configure`.

| Annotation  | Value |
| ----------- | ----- |
| Read-only   | false |
| Destructive | true  |
| Idempotent  | true  |

Review the target and effect with the user before running this tool. An idempotent annotation does not make an action reversible.
