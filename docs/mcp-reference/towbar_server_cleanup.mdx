`towbar_server_cleanup`

Request server-level cleanup of unused Towbar objects. Revalidates ownership and usage, and protects active workloads, manifest conflicts, pending retirements and shared resources. Permanent workload removal is a separate retirement action. Confirm server cleanup with the user before requesting it.

## Access and behavior

Choose **Administrator** when approving the [MCP connection](/docs/api/mcp). Your current team role and approved permissions constrain access.

Required permissions: `server.remove`.

| Annotation  | Value |
| ----------- | ----- |
| Read-only   | false |
| Destructive | true  |
| Idempotent  | true  |

Review the target and effect with the user before running this tool. An idempotent annotation does not make an action reversible.
