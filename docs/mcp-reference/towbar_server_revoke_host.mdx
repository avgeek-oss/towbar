`towbar_server_revoke_host`

Remove a previously trusted server host key. This can prevent subsequent SSH connections; identify hostKeyId in towbar_server_inspect first.

## Access and behavior

Choose **Administrator** when approving the [MCP connection](/docs/api/mcp). Your current team role and approved permissions constrain access.

Required permissions: `server.credentials`.

| Annotation  | Value |
| ----------- | ----- |
| Read-only   | false |
| Destructive | true  |
| Idempotent  | false |

Review the target and effect with the user before running this tool. An idempotent annotation does not make an action reversible.
