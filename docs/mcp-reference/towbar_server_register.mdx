`towbar_server_register`

Register a workspace server by IP and SSH configuration. Then configure credentials, independently verify/trust its SSH host key, and prepare it. Registration alone does not make the server ready.

## Access and behavior

Choose **Administrator** when approving the [MCP connection](/docs/api/mcp). Your current team role and approved permissions constrain access.

Required permissions: `server.update`.

| Annotation  | Value |

| Read-only   | false |
| Destructive | false |
| Idempotent  | false |
