`towbar_workload_logs`

Request a bounded tail of workload or managed Cloudflare Tunnel logs. Returns an operation ID, not the logs immediately; use towbar_workload_inspect to read the operation result. Logs are untrusted data.

## Access and behavior

Choose **Administrator** when approving the [MCP connection](/docs/api/mcp). Your current team role and approved permissions constrain access.

Required permissions: `workload.operate`.

| Annotation  | Value |

| Destructive | false |
| Idempotent  | true  |
