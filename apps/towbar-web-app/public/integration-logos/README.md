- OCI registries and Infisical reuse `/resource-logos/docker.webp` and `/resource-logos/infisical.webp`; their sources and licenses are recorded in the [resource logo catalog](../resource-logos/README.md).
- `doppler.svg`: unchanged vector from [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons/blob/f651f5798c7d58bff3cff4d3a9c4645d87657bbd/svg/doppler.svg), Apache-2.0. The collection license is included in [LICENSE-dashboard-icons](../resource-logos/LICENSE-dashboard-icons).
